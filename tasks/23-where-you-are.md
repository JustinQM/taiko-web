# 23 — Where you are in the folder

A folder can hold five hundred songs and the wheel gives no clue which
one of them you are on.

YataiDON has a counter in the same corner, but it is not this: its
"Song 3" is how many songs you have played this credit. This is ours.

## What it changes

A count of the position within the current listing, drawn in song
select while inside a folder. Not shown at the root, where the entries
are folders and menu items and a position means nothing.

## How it will be shown to work

Enter a folder, move, and the number tracks the cursor; leave, and it
goes away.
