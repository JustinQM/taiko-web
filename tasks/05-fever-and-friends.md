# 05 — Fever, footer, renda, chibi

The rest of the standard background, in the order they matter:

- **fever** — the background changes when the gauge reaches clear, which
  is the one piece of it that reacts to how you are playing
- **footer** — static, cheap, and the bottom edge looks unfinished
  without it
- **renda** and **chibi** — if they fall out of the structure already
  built; skipped if they do not

Collab backgrounds are not in scope: ten more variants for specific
licences, none of which our library has.

## How it will be shown to work

The background changes state when the gauge crosses clear and changes
back if it drops. Frame cost measured as before.
